# PPO vs OpenAI-ES - Unity-projektin lähdekoodi

Tämä repositorio sisältää maisterintutkielmassa kehitetyn kilpailullisen pöytälätkäpelin Unity-projektin lähdekoodin.

Projekti sisältää kaikki pelin kehittämiseen tarvittavat resurssit, kuten Unity-skenet, C#-lähdekoodin, prefabit, materiaalit, sekä muut Unity-projektiin kuuluvat tiedostot.

Tämä on projektin lopullisen pelin lähdekoodi, ei koulutuksessa käytetyn ympäristön lähdekoodi.

# Unity-versio

Projekti on rakennettu ja testattu seuraavalla Unity-versiolla:

**Unity 6000.2.6f1**

Projektin avaamista muilla Unity-versioilla ei suositella, sillä Unity ei takaa projektien täydellistä yhteensopivuutta eri versioiden välillä.

---

# Repositorion sisältö

Repositorio sisältää Unity-projektin lähdekoodin sellaisenaan.

Tyypillinen kansiorakenne sisältää esimerkiksi:

```text
Assets/
Packages/
ProjectSettings/
UserSettings/
```

Lisäksi projektissa sijaitsevat kaikki pelin toteutukseen liittyvät resurssit, kuten:

- C#-skriptit
- Unity-skenet
- prefabit
- materiaalit
- tekstuurit
- pelilogiikka
- agenttien käyttämät komponentit
- käyttöliittymä

---

# Projektin avaaminen

Projektin avaaminen edellyttää Unity Editoria.

1. Käynnistä Unity Hub.
2. Lisää tämä repositorio projektiksi (**Add Project**).
3. Avaa projekti käyttäen Unity-versiota **6000.2.6f1**.

Kun projekti on avattu onnistuneesti, peliä voidaan:

- tarkastella
- muokata
- rakentaa uudelleen (Build)
- käyttää uusien ominaisuuksien kehittämiseen
